# commit-history.json

## Purpose
Checked-in account commit activity and per-project highlights, generated by `npm run history:refresh`.

## Schema
Version 2; calendar `GitHub contribution days`; scope `public commit contributions`; refresh timestamp. `account` contains the GitHub login, sorted nonzero daily counts, total, and first/last contribution dates. `projects` contains the same aggregates for each mapped project, plus its verified repository names.

## Contracts
Do not edit counts manually. Both layers count contributions credited by GitHub to the same account and dates. Project daily counts cannot exceed overall daily counts. Other repositories contribute to the overall total even when absent from the portfolio. Public counts only; no private repo identities, author emails, commit messages, or credentials are stored.

The schema intentionally replaces raw all-author repository history: a personal project share must use the same attribution and calendar as the personal activity background.

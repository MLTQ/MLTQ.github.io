# commit-history.json

## Purpose
A checked-in snapshot of public project commit activity, generated by `npm run history:refresh`. Ordinary builds and visitors work without GitHub access.

## Schema
Version 1, UTC calendar, refresh timestamp, and records keyed by stable project slug. Each record holds sorted nonzero daily counts, total unique commits, first and last dates, plus repository names, default branches, pinned heads, and per-repo totals. Missing calendar days inside the first-to-last interval mean zero commits.

## Contracts
Never edit counts by hand. The collector validates complete pagination and replaces this file atomically. Counts include merges and all authors reachable from each default-branch head. Grouped projects deduplicate shared commit SHAs. No messages, emails, or private repository data are stored.

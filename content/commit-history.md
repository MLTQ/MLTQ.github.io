# commit-history.json

## Purpose
Checked-in GitHub profile activity and public project commit highlights, generated by `npm run history:refresh`.

## Schema
Version 3; calendar `GitHub contribution days`; scope `GitHub profile contributions`; refresh timestamp. `account` contains the login, nonzero daily counts, `totalContributions`, `firstContribution`, and `lastContribution`. Project records contain public repository names, daily commit counts, `totalCommits`, `firstCommit`, and `lastCommit`.

## Contracts
The background matches GitHub's full profile calendar, including anonymized private activity and non-commit contributions. Project highlights count public commits credited to the same account. Dates are identical across layers; project commits cannot exceed calendar contributions on any day.

Do not edit counts manually. Persist only daily aggregate calendar counts and public project identities. No private repository identities, author emails, commit messages, or credentials are stored. Private contribution counts follow the owner's existing GitHub profile visibility.
